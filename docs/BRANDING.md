# Toolbox application identity

The current application mark was generated with the built-in image-generation tool on 15 October 2026. Three interconnected folded bands express the connected decision, scope and story workflow. Indigo and mint continue the existing product palette. The transparent raster master supplies the application identity and its delivery variants.

The original official README hero at `docs/assets/toolbox-hero.svg` remains unchanged and first in both README files. Document logos in Brand Studio remain project-specific.

## Assets

- [Transparent master PNG, 1254 × 1254](../public/brand/toolbox-logo.png).
- [Lossless 128 × 128 WebP](../public/brand/toolbox-mark-128.webp), used by the sidebar and settings.
- [32 × 32 favicon](../public/brand/favicon-32.png), [192 × 192 icon](../public/brand/icon-192.png) and [180 × 180 touch icon](../public/brand/apple-touch-icon.png).

Delivery variants are mechanical downsampling and encoding of the generated master, with alpha preserved. The image-generation output is copied into this repository; no application asset depends on a private local path. The replaced SVG mark and favicon remain available in Git history.

## Generation prompt

Built-in generation with `transparent_background: true`, without a reference image or API-key workflow:

> Use case: logo-brand. Asset type: production application logo symbol for IT Productivity Toolbox, a professional open-source suite connecting decision traceability, scope analysis and user story refinement with branded reporting. Create ONE refined, distinctive emblem, no wordmark or text. Concept: three precisely crafted interlocking folded bands forming a compact architectural T / connected workflow knot with a clear central negative-space path, conveying clarity, continuity and trustworthy delivery. Premium contemporary software identity with meticulous optical balance, sophisticated subtly dimensional material, crisp clean silhouette, broad readable forms that survive 32px, restrained bevel highlights, no fine decorative lines. Palette from the existing product: deep indigo, luminous periwinkle and a small cool mint accent. The emblem itself should have substantial saturated dark edges so it works on white and dark charcoal. Square composition, centered, symbol occupies about 82% of canvas, perfectly transparent outside the emblem. No surrounding tile, no background, no shadow outside the symbol. No generic toolbox, gears, checkmark, letters, clipart, mockup, slogan, watermark or extraneous objects. This must feel like a professionally art-directed brand asset, not a basic SVG placeholder.
