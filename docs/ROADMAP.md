# Roadmap

Roadmap items describe priorities, not delivery promises. A focused, trustworthy workflow takes precedence over adding another tool.

## 0.1 — Functional foundation

- [x] Static, local-first React/TypeScript application and isolated project aggregates.
- [x] Decision journal, meaningful history, filters, archive and exports.
- [x] Explicit baseline freeze/revisions, change ledger, comparison and safe what-if simulation.
- [x] Deterministic English/French story heuristics and controlled refinement notes.
- [x] Typed, bidirectional relationships between records.
- [x] Validated full backups and non-destructive restoration as copies.
- [x] English and French interface, light/dark/system themes and responsive navigation.
- [x] Unit/component/browser checks, CI workflow, authentic screenshots and maintainers’ documentation.

These checkboxes describe implemented scope. See [testing](TESTING.md) and the latest CI run for validation evidence and [handoff](HANDOFF.md) for known limitations.

## Next — Confidence and usability

1. Exercise Firefox/WebKit and conduct manual screen-reader and zoom/reflow review.
2. Test with IT Project Managers, Product Owners and Scrum Masters; measure whether a new user can record a decision and explain a scope change without guidance.
3. Review French phrasing with native users and extend story rule fixtures from consented, anonymized examples.
4. Add explicit recovery/import diagnostics for individual invalid records without weakening validation.
5. Evaluate large-project performance, backup file size UX and a normalized schema if real usage justifies it.
6. Consider multilingual human-readable report headings while retaining stable machine-readable contracts.
7. Choose a static demo host and deployment policy in a separate, explicit publication step.

## Later — Only with demonstrated value

- Selective import/merge with conflict review and migration fixtures.
- Proposed-change edit history, richer dependency review and saved simulation scenarios.
- Optional integrations through clearly scoped import/export adapters.
- Remote analysis only behind a server-side secret boundary, informed content consent, meaningful limits, and a useful local fallback.

Accounts, subscriptions, a task tracker, and schedule/financial prediction are outside the current product direction.
