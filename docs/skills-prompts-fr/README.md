Les exemples et résultats attendus sont rédigés manuellement. Aucune campagne d’exécution auprès de modèles n’a été réalisée pour cette édition du 19 novembre 2026. Les données sont fictives ; les variantes de réponse sont acceptables si elles respectent les critères.

Pour évaluer un prompt, transmettre uniquement ses consignes et les données de l’exemple, puis comparer la réponse aux critères sans les avoir inclus dans la demande. Conserver la version du prompt, le logiciel utilisé, les résultats et les corrections nécessaires.
